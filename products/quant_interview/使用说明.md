# 量化面试概率题 30 道 · v1 · 使用说明

谢谢购买！这份资料适合准备量化研究 / 量化交易 / 数据科学 / 数据分析岗位面试的同学。

## 里面有什么

| 文件 | 是什么 |
|---|---|
| `量化面试概率题30道_v1.pdf` | 题目册 + 解析册。先做题，再看解析 |
| `题库.md` | 同样的内容，纯文字版，给 AI 读 |
| `quant-interview-coach/` | Claude 用的 AI 陪练 Skill（Claude Code / Claude 网页版） |
| `通用提示词.md` | DeepSeek、Kimi、豆包、ChatGPT 等用的 AI 陪练提示词 |
| `verify.py` | 30 道题的 Python 模拟验证代码，自己能跑 |

每道题都有：中英双语题目、提示、答案、解法步骤、常见错误、面试时英文怎么说、追问，以及 Python 模拟验证。

## 三种用法

**1. 只看 PDF**：先自己做题册，限时 5 分钟一道，做完再翻解析。

**2. 用 Claude 当陪练**
- Claude Code：把 `quant-interview-coach` 整个文件夹放进 `~/.claude/skills/`，然后对 Claude 说「出题」。
- Claude 网页版：把 `quant-interview-coach` 文件夹压缩成 zip，在设置里的 Skills（技能）页面上传（以当前界面为准），然后在对话里说「出题」。

**3. 用其他 AI 当陪练**：打开 `通用提示词.md`，按里面的步骤做。

## 自己跑验证代码

```bash
pip install numpy
python verify.py
```

会打印每道题的「公式值」和「模拟值」。代码固定了随机种子，跑出来的数和 PDF 里一样。
