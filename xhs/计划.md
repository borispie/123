# 小红书副业计划：量化面试概率题

## 一句话

照那条推文的路子做：低价虚拟产品 + 每天发笔记引流。但把「雅思」换成你最有资格讲的「量化 / 数据岗面试」。
产品（30 题 PDF + AI 陪练 + 验证代码）和 30 篇笔记已经做好了，你要做的是开号、开店、每天手动发。

## 推文那套，哪些能抄，哪些别碰

| 能抄 | 别碰（会封号、下架或违法） |
|---|---|
| 39–99 元的低价虚拟产品，冲动消费区 | 买别人的产品让 AI「洗稿」再卖：这是侵权。被投诉会下架、店铺扣分。拿洗稿的东西去申请版权证明更是坑自己 |
| 「你付过钱的东西 = 真需求」这个选题方法 | 文件、私信、评论里放微信 / 二维码：算站外导流，小红书会处罚 |
| 一条链路收钱：产品 → 1v1 陪练 → 定制 | 卖 Claude 账号、代充、卖 token、中转 API：违反 Anthropic 的服务条款，号会被封 |
| 模仿爆款的「结构和角度」，内容全换成自己的 | 用 AI 托管工具自动发帖：小红书 3 月起严打，全是 AI 代发的号直接封 |
| 客户少于 50 不建群；不同产品的客户分开建群 | 把他的「20 万浏览、20 天 4 万」当成你的预期：这是幸存者偏差，大部分人发 30 篇也没有一篇爆 |

## 为什么选「量化面试题」，不选「教人用 Claude」

| 方向 | 卷不卷 | 买家能直接用吗 | 你的优势 | 见钱速度 | 天花板 |
|---|---|---|---|---|---|
| **量化 / 数据面试题 + AI 陪练（推荐）** | 中低 | 能。PDF 不需要 AI；陪练 DeepSeek、Kimi 也能用 | 统计专业 + 量化实习，最真实 | 2–4 周 | 中：后面接 1v1 模拟面试 |
| 泛 Claude Code 教程 | 很卷 | 国内用户要翻墙 + 海外账号，小红书上还不能明说 | 你确实在用，这个仓库就是作品 | 不确定 | 高但不稳，功能一更新内容就过时 |
| WHOOP 中文手册（闲鱼顺手加售） | 很低 | 能 | 已经有闲鱼买家 | 最快 1–2 周 | 很低 |
| 统计 / R 复习资料（留学生） | 中 | 能 | 专业对口 | 4–8 周 | 中；碰代写就违规 |
| Pine 指标 / 回测脚本卖给 X 粉丝（收美元） | 中 | 能 | 作品集现成 | 慢，看 X 粉丝数 | 中 |

你说的「教人用 Claude」没丢，放在副线：每周 1 篇「我怎么用 Claude Code 做 X」，带泛流量，也给产品引流（见下面「Claude Code 副线」）。
产品本身就是一个 Claude Skill，「我用 Claude Code 做了个量化面试陪练」就是推文那种标题。

## 免费和付费怎么分

- 笔记：每天公开 1 道（题目、解析、代码都给），用来涨粉、建立信任。
- 店铺版：一次拿到全部 + PDF 题目册 + AI 陪练 + 验证代码，不用等 30 天。准备面试的人等不起。
- 以后加的第 31–60 题**只放店铺版**，不发笔记。到时候价格从 39 涨到 69，老买家免费更新。

## 钱怎么算（目标 $20/月 → $100/月）

粗算 1 美元 ≈ 7 人民币（以当天汇率为准），平台扣点以后台为准，下面没算进去。

| 目标 | 约合 | ¥39 要卖几单 | ¥69 要卖几单 |
|---|---|---|---|
| $20/月（Pro） | ≈ ¥140 | 4 单 | 3 单 |
| $100/月（Max） | ≈ ¥700 | 18 单 | 11 单（或 5 单 + 2 次 ¥199 的 1v1） |

要多少浏览：**我假设**每 1000 次笔记浏览出 0.3–1 单（我拍的数，不是查到的，跑两周用你自己的数据换掉）。
那么 $20 要每月 4 千–1.3 万浏览，$100 要每月 1.8 万–6 万浏览。

## 多久能见到钱（我的估计）

| 目标 | 时间 | 我给的概率 |
|---|---|---|
| 第一单 | 店铺开通后 2–4 周 | 约 55% |
| 稳定 $20/月 | 第 1–2 个月 | 约 50% |
| 稳定 $100/月 | 第 3 个月左右 | 约 20% |

这些是先验，不是查到的数。最大的变量是有没有一篇笔记爆（1 万+ 浏览）：没有爆款的话，第一个月可能只有几单。
跑满 14 篇后把 `data/xhs_stats.csv` 给我，我用你的真实浏览和转化更新这张表（贝叶斯更新，正好是你的人设）。

最快的一笔钱可能不是题库，是 1v1：评论区或私信有人问「能不能带我练」，一次 ¥99–199 的模拟面试就够 $20。

## 30 天怎么走

### 第 0 周（这周末，2–3 小时）

1. **开号**：名字带「统计」「量化」之类的词。简介：「美本统计大四｜量化实习｜每天一道面试概率题」。
   先正常刷 2–3 天量化、留学求职的笔记，点赞收藏几篇，别一上来就发。
2. **开店**：App 里找「开店」，个人店用身份证实名。【需确认：虚拟商品 / 学习资料类目能不能上、要什么资质、审核几天】
   上不了就先挂闲鱼（你已经有号），小红书只做内容。
3. **把产品从头看一遍**：`output/products/量化面试概率题30道_v1/`。重点看 30 道题的解法你认不认，上面署的是你的名字。有不对的告诉我改。
4. **重新打包**：`python scripts/build_quant_pack.py --handle 你的小红书号`，压缩包传网盘（百度、夸克都行）。
5. 商品标题、详情页、FAQ 直接复制 `products/quant_interview/店铺商品文案.md`，主图用 `output/products/…_商品主图.png`。

### 第 1–2 周：每天 1 篇（每天 30–40 分钟）

- `python scripts/make_xhs_notes.py --start 开始日期` 出图和文案。每天打开一个 `output/xhs/D几/`，看一遍，**手动**发。
- 发布时间：北京时间晚上 8 点左右（现在夏令时 = 美东早上 8 点；11 月 1 日以后冬令时 = 美东早上 7 点）。
- 发完 1 小时内回评论。有人要题库 → 回「主页店铺有」，不发微信。
- 每篇发出 48 小时后，在 `data/xhs_stats.csv` 记一行。
- 店铺开了以后加 `--shop` 重新生成，正文最后会多一句引导。

### 第 3–4 周：看数据调整

- 哪类题浏览高就多发那类（改 `products/quant_interview/questions.py` 最下面的 `ORDER`）。
- 每周 1 篇 Claude Code 副线笔记。
- 有 5 个以上人问 1v1 → 上架「1v1 模拟面试 60 分钟」。
- 开始做 31–60 题（只放店铺版），让我按同样格式写、用 Python 验证。

## Claude Code 副线（每周 1 篇，要你自己录屏）

1. **「我用 Claude Code 做了个量化面试 AI 陪练」**：录在 Claude Code 里说「出题」→ 它出题、判分、追问的过程。顺便给产品引流。
2. **「我让 Claude Code 每天自动出数据图」**：录 `./daily.sh` 跑完出图的过程。只讲流程，不聊币价（小红书对币圈内容管得严）。
3. **「AI 帮我整理概率题，心算错了一道，Python 模拟抓出来了」**：真事。组合波动率那道题一开始心算成 20%，跑模拟才发现是 21.8%。适合讲「为什么每道题都要模拟验证」。

## 红线

1. 不洗别人的付费产品。题库里是经典概率题，文字、解析、代码都是原创。
2. 不站外导流：笔记、评论、私信、文件里都不放微信、二维码、外链。用小红书自己的群聊沉淀买家（满 50 人再建群）。
3. 不用自动发帖工具，自己手动发。发布时如实声明 AI 辅助。
   （小红书 2026 年 3 月 10 日发了打击 AI 托管账号的公告，4 月 27 日发了 AI 内容标识规则。来源：IT之家、澎湃新闻的报道，我只看到搜索摘要，原文没打开。）
4. 小红书上不发币圈内容。币圈继续放 X。
5. 不卖 Claude 账号、代充、token、中转 API。
6. 不碰代写作业、代考：只卖学习资料和陪练。
7. 身份：如果你是 F-1 学生，在美国境内做这种有收入的生意（包括 1v1 收费辅导）可能影响身份。开店前问一下学校的国际学生办公室（DSO），这个我没法替你判断。
8. 仓库现在是公开的。加 31–60 这些只放店铺版的题之前，先把仓库改成私有（GitHub → 仓库 Settings → 最下面 Danger Zone → Change visibility）。
